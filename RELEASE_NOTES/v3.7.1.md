Version **v3.7.1** adds **HSWQ Load CLIP Vision**, a drop-in replacement for ComfyUI's stock "Load CLIP Vision" node, with native **ConvRot INT8** support for CLIP Vision packs.

Code commit `7180476`. Full node documentation: [README.md (Nodes section)](https://github.com/ussoewwin/ComfyUI-HSWQ-Loader-and-Tools/blob/main/README.md).

---

### What's new

1. **HSWQ Load CLIP Vision node** (category `loaders`, input `clip_name`, output `CLIP_VISION`):
   - Float packs (no `comfy_quant`): byte-identical to stock `Load CLIP Vision` — same key-layout auto-detection (OpenAI `visual.` prefix, ViT-g/H, SigLIP, SigLIP2, ViT-L-336 (+LLaVA projector), ViT-L, DINOv2, DINOv3), same preprocessing, same output (`last_hidden_state` / `image_embeds` / `penultimate_hidden_states` / `image_sizes` / `mm_projected`).
   - ConvRot INT8 packs (`CLIP-ViT-H-14_hswq_convrot_int8.safetensors`, etc.): ConvRot INT8 layers are swapped in-place for `mixed_precision_ops` `Linear` (`int8_tensorwise`, `convrot=True`) and their INT8 codes / `weight_scale` are loaded, so the tower runs a real INT8 GEMM via `comfy_kitchen` instead of dequantising to float.
   - Standard `CLIP_VISION` output — consumable by `CLIP Vision Encode`, IPAdapter, Style Model, PuLID, etc.

2. **Format guard for non-INT8 packs**:
   - Only packs whose `comfy_quant` layers are all `int8_tensorwise` are accepted.
   - Any other declared format (`nvfp4`, `float8_e4m3fn`, `float8_e5m2`, `w6a8_int8`, `asym_w4a8_int8`, `mxfp8`, `convrot_w4a4`, or unreadable) is rejected with an explicit `RuntimeError` instead of silently running on codes-as-float.
   - Float packs (no `comfy_quant`) keep the stock path byte for byte.

### Verification across architectures

| Architecture | Model Checkpoint | Result |
| :--- | :--- | :--- |
| **CLIP Vision FP16 (stock path)** | `CLIP-ViT-H-14.safetensors` | **PASS**: image_embeds (1, 1024), all finite |
| **CLIP Vision ConvRot INT8** | `CLIP-ViT-H-14_hswq_convrot_int8.safetensors` | **PASS**: 92 / 92 declared layers armed, INT8 GEMM (`comfy_kitchen::int8_linear`, `quantize_int8_rowwise_convrot64_kernel`), params.convrot=True, scale float32 (1280, 1), cosine(INT8, FP16) = 0.999988, rel_l2 = 0.496 %, last_hidden_state cos = 0.999090, all finite |
| **CLIP Vision FP16 (OpenAI .bin)** | `clip-vit-large-patch14-336.bin` | **PASS**: model_type=clip_vision_model, emb=(1, 768), finite |
| **CLIP Vision FP16 (dynamic VRAM)** | `CLIP-ViT-H-14.safetensors` (aimdo + ModelPatcherDynamic) | **PASS**: cosine 0.999988, vram allocated 1 MB |
| **Non-INT8 format guard** | synthetic nvfp4 pack | **PASS**: raises RuntimeError (explicit rejection, no silent garbage) |
