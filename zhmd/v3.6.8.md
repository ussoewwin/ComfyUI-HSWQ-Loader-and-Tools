# Release Notes（中文）：v3.6.8 修复 stock CheckpointLoaderSimple 加载 SDXL ConvRot INT8 全黑图（ComfyUI v0.44 更新后）

版本 **v3.6.8** 修复了 ComfyUI 更新至 **v0.44.0** 后，SDXL **ConvRot INT8** checkpoint 通过 **stock `CheckpointLoaderSimple`** 节点加载时输出**整图全黑**的问题，同时修好了随之暴露的 `PromptServer.instance` 兼容崩溃。修复提交 `00bc498`。

---

### 1. 故障现象

- workflow 正常跑完（无报错、节点 success），但解码结果是一张**全黑**的图。
- 同一 workflow 使用 FP16 checkpoint（同底模）时输出完全正常，说明这是 **INT8 专属**问题。
- 更新 ComfyUI 前该配置一切正常 —— 失败集中在 **v0.44 core + stock 加载路径**的组合上。

### 2. 实测定位（逐层 hook 探针）

对 `apply_model` 单次前向逐层插桩实测（sigma=10，y=zeros，64x64 latent，固定 seed）：

| 层 | 实测输出 |
|---|---|
| `input_blocks.2.0` conv1（INT8 路径） | mean -86.6, **std 858.6**, max 3984（有限，但比正常大约 100 倍） |
| `input_blocks.2.0` out_conv | mean 38.7, **std 475.0**, max 2530 |
| `input_blocks.3.0.op`（量化 Conv2d） | **out = inf**（全模型首个 inf；其输入本身有限） |
| `input_blocks.4.0.in_layers.0`（GroupNorm） | **out = NaN（327,680 个元素全 NaN）** |
| DiT 最终输出 | **163,840 个元素全 NaN** |

同时实测 CLIP 文本编码器完好（cond shape (1,77,2048)，mean -0.0347，std 1.1752，nan 0）——故失败**只在 DiT 侧**。inf 进入 GroupNorm 转成 NaN 并随网络传播至采样与 VAE 解码，输出即为均匀黑色。

### 3. 根因

**ComfyUI 自带的 `MixedPrecisionOps` 一直没有 `Conv2d` 类**（v0.42.5 与 v0.44.0 双侧经 git 历史实测：内部只有 `Linear` / `MoEExperts` / `Embedding`）。HSWQ 的量化 Conv2d（`_make_quantized_conv2d`）只在 **INT8 conv scope 打开期间**被注入到该 ops 类中，而 scope 由 loader 专用加载路径打开 —— **stock `CheckpointLoaderSimple` 途经 `comfy.sd.load_checkpoint_guess_config`，从不打开 scope**。于是 v0.44 下：

1. `model_config.quant_config` 被检测到（`{'mixed_ops': True}`），`pick_operations` 返回 `mixed_precision_ops(...)`；
2. `_should_inject_int8_conv` 因 scope 关闭返回 **False** —— **HSWQ 量化 Conv2d 未被注入**；
3. `Conv2d` 落到 stock `manual_cast.Conv2d`，其 `_load_from_state_dict` 是 stock 装载而不走 `_load_quantized_module`，**int8 原始值直接 cast 成 fp16 存储，`weight_scale` 从未应用**；
4. 权重比正确值大 `1/scale_i` ~ **1300 倍**（实测 loader 侧 std 29.255 vs 正确 dequant std 0.02229），forward 激活值在数层内溢出 fp16（实测首个 inf 在 `input_blocks.3.0.op`），其后全链路 NaN —— 全黑图。

FP16 checkpoint 完全不受影响，因为其加载根本不走向量化路径。

### 4. 修复方式

新增 `_patch_checkpoint_loader_simple_int8_scope()`（`patches/comfy_quant_int8.py`）：围绕 `comfy.sd.load_checkpoint_guess_config` 的 wrapper，**仅当 checkpoint 为 SDXL/SD1.5 系 INT8 pack**（block key 检测 `checkpoint_needs_hswq_int8_conv2d`：存在 `input_blocks`/`middle_block`/`output_blocks` 且无 DiT block key）时，在加载窗口打开 `_int8_quant_conv_scope()`。scope 内 loader 的 `mixed_precision_ops_force_conv` 注入 HSWQ 量化 Conv2d，其 `_load_from_state_dict` 构建真实 `QuantizedTensor`/`TensorWiseINT8Layout` 权重（scale 与 ConvRot 元数据齐全）并在线激活旋转。wrapper 由 `_hswq_ensure_loader_scope_at_import()` 在 **import 时安装**，stock 路径一举生效；Krea2 / FLUX/DiT / MOSS 等 scope 外的 checkpoint **完全绕开**。**ComfyUI core 未改一行。**

同时修复 `PromptServer.instance` 兼容（`model_management_mgpu.py`，3 处 `getattr` 保护）。

### 5. 实测结果

| 量 | 修复前 | 修复后 |
|---|---|---|
| `op.weight` 类型 | fp16 Parameter（int8 原始值） | QuantizedTensor / TensorWiseINT8Layout |
| `_hswq_convrot` | 不存在 | True |
| 使用中的 Conv2d 类 | stock manual_cast（module `comfy.ops`） | HSWQ Conv2d（module `…patches.comfy_quant_int8`） |
| forward 输出 | 全 NaN（163,840/163,840） | mean -0.0344 / std 0.7010 / nan 0 / inf 0 |

FP16、Krea2、FLUX/DiT、MOSS 工作流不受影响；接口与行为保持不变（分离维护，ComfyUI core 未修改）。
