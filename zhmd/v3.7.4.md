# Release Notes（中文）：v3.7.4 HSWQ SAM3 Loader（ConvRot INT8）—— 修复打开保存的工作流时误报模型缺失

## 概述

**修复 HSWQ SAM3 Loader（ConvRot INT8）：打开保存的工作流时不再把模型标记为缺失。** v3.7.3 为该加载器加入了文件夹路径输入（`sam3_name` + 必填的 `sam3_dir`）与 CLIP 输出。打开保存的工作流时，前端会把恢复出来的文件名与下拉列表的选项比对；而此时选项列表仍属于恢复之前设置的文件夹，因此该节点被标记为「缺失模型」，尽管文件实际存在。v3.7.4 在下拉列表填入恢复出的文件夹的选项后，重新执行前端的缺失模型扫描，节点不再被误报为缺失。文件下拉列表仍会跟随 `sam3_dir` 中填写的文件夹，模型仍只从该文件夹加载，非 INT8（FP16）SAM3 检查点仍正常加载。

---

## 特性

- **打开工作流时不再误报「缺失模型」**：下拉列表为恢复出的文件夹重新填入选项后，重新执行缺失模型扫描，清除过时的警告。
- **SAM3 ConvRot INT8 pack 的直接替代加载器（不变）**：输入 `sam3_name` + `sam3_dir`，输出 `model`（MODEL）+ `clip`（CLIP）。
- **任意文件夹（不变）**：`sam3_dir` 为必填。模型只从该文件夹加载；留空会被拒绝，不会回退到其它文件夹。
- **CLIP 输出（不变）**：检查点的文本编码器以标准 ComfyUI `CLIP` 输出暴露，可直接接入 `CLIPTextEncode`（文本条件检测）。
- **自动硬件安全回退（不变）**：非对齐层（`K % 4 != 0`）以 float 精度计算，避免 cuBLAS INT8 GEMM 崩溃。
- **原生 INT8 VRAM 驻留（不变）**：权重保持 8 位（`TensorWiseINT8Layout`），显著降低显存占用。
- **无缝兼容 FP16（不变）**：FP16 SAM3 检查点以 ComfyUI 原生设置加载（不附加 `MixedPrecisionOps`，行为不变）。

---

## 兼容性

- **HSWQ SAM3 Detect**：加载器的 `model` 输出接入 `HSWQ SAM3 Detect`（分类 `HSWQ/Detection`），输出 masks / bbox / image。
- **ComfyUI 原生 SAM3 检测 / 跟踪节点**：`MODEL` 输出为标准 ComfyUI 模型。
- 仅支持由 [Hybrid-Sensitivity-Weighted-Quantization](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization) 生成的检查点；其他第三方 SAM3 量化包不在支持范围内。
