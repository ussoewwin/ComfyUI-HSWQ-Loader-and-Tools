# Release Notes（中文）：v3.6.7 HSWQ Moss-Image Prompt Enhancer 节点与视觉大模型集成

版本 **v3.6.7** 正式为 ComfyUI-HSWQ-Loader-and-Tools 引入了 **HSWQ Moss-Image Prompt Enhancer**（`HSWQMossImagePromptEnhancer`）节点。该节点基于视觉语言模型（VLM）与完整的 MOSS-Image 官方提示词工程规范，能够将简短的构思与参考图像自动扩写为兼具 8 大核心视觉维度的超高质量丰富提示词，并同时提供文本与 Conditioning 双重输出。

![HSWQ Moss-Image Prompt Enhancer](https://raw.githubusercontent.com/ussoewwin/ComfyUI-HSWQ-Loader-and-Tools/main/png/prompt_enhancer.png)

---

### 核心功能与技术实现

1. **视觉大模型（Vision LLM）原生集成**
   - 自动扫描并加载 ComfyUI 标准 `models/clip` 目录下的多模态模型文件（通过 `folder_paths.get_filename_list("clip")`），提供便捷的模型下拉列表。
   - 支持图生文（Image-to-Text）与视觉引导的多模态提示词扩充。

2. **完整 MOSS-Image 8,398 字符官方系统提示词规范**
   - 节点内部完整嵌入 8,398 字符的 MOSS-Image 官方提示词工程指令体系，确保每次扩充均覆盖 8 大专业视觉维度：
     1. **主体描述 (Subject)**：核心主体、姿态动态、面部表情、材质纹理与服饰细节。
     2. **艺术风格 (Style)**：超写实摄影、油画、赛博朋克、动漫原画、电影级 CGI 等。
     3. **氛围意境 (Atmosphere)**：叙事基调、情绪张力、空灵清冷或温暖治愈等情感共鸣。
     4. **构图景深 (Composition)**：机位视角、景别、焦距、光圈景深虚化与三分法构图。
     5. **光影架构 (Lighting)**：主光源、轮廓光、丁达尔体积光、次表面散射（SSS）与漫反射环境光。
     6. **色彩配比 (Color Palette)**：色相冷暖、主色调、色彩饱和度与胶片调色风格。
     7. **微观细节 (Fine Detail)**：微观几何结构、毛孔质感、细微划痕、镜面高光与空气微尘。
     8. **介质材质 (Technical Medium)**：传感器画质、虚幻引擎5/Octane渲染材质、镜头眩光与胶片颗粒感。

3. **思维链抑制机制 (`<think>` Loop Suppression)**
   - 针对现代具备推理能力的多模态大模型（如 DeepSeek-R1 蒸馏系、Qwen-VL-Coder），模型容易陷入递归推理循环。
   - 节点在推理管道中自动注入 `<think>\n\n</think>\n`，绕过内部冗余思考 Token，强制模型立即输出最终的高质量丰富提示词。

4. **双重输出架构（Dual Output）**
   - **`conditioning`**：直接通过输入的 CLIP 模型对扩充后的高质量提示词进行编码，无缝接入扩散模型采样器（KSampler、FluxSampler 等）。
   - **`expanded_caption`**：输出扩充后的纯文本字符串，便于调试核对、日志记录或后续文本后处理。

5. **全流程同步与实机部署**
   - 代码已与实机环境 `D:\USERFILES\ComfyUI\ComfyUI\custom_nodes\ComfyUI-HSWQ-Loader-and-Tools` 保持 100% 字节级一致。
   - 节点说明与 UI 图示已同步更新至 [zhmd/README.md](https://github.com/ussoewwin/ComfyUI-HSWQ-Loader-and-Tools/blob/main/zhmd/README.md)。
