# Release Notes（中文）：v3.7.2 HSWQ Load IPAdapter Model 节点 - 支持 ConvRot INT8 IP-Adapter 模型

版本 **v3.7.2** 新增 **HSWQ Load IPAdapter Model** 节点，作为 ComfyUI IPAdapter Plus 的 `IPAdapter Model Loader` 的直接替代品，原生支持从任意文件夹加载 IP-Adapter 模型，包括 **ConvRot INT8** pack。

---

### 1. 新增功能

1. **HSWQ Load IPAdapter Model 节点**（分类 `loaders`，输入 `ipadapter_file` + `ipadapter_dir`，输出 `IPADAPTER`）：
   - Float pack（无 `comfy_quant`）：与内置节点逐字节等价 —— 相同的 key 布局自动识别（`image_proj` / `ip_adapter`）、相同的 `plusv2` / `unnorm` 文件名标志、相同的输出。
   - ConvRot INT8 pack：INT8 代码保持 INT8 —— 不会被反量化。每个声明层被安装为 `ConvRotInt8Linear`，其 `int8_weight` 缓冲保存 INT8 代码、`weight_scale` 缓冲保存 float32 的 per-out-channel scale，forward 调用 `comfy_kitchen.int8_linear(..., convrot=True)`，因此 Hadamard 激活旋转发生在 INT8 GEMM 内部。
   - 标准 `IPADAPTER` 输出 — 可供 IPAdapter Plus 的 `IPAdapter` / `IPAdapter Advanced` / `IPAdapter Unified Loader` 使用。

2. **任意文件夹加载**：
   - `ipadapter_dir` 为必填项。模型只从该文件夹加载；留空会被拒绝，不会回退到其它文件夹。

3. **运行时补丁**：
   - IP-Adapter 扩展的 `To_KV` 与 `IPAdapter` 类在运行时被替换（不修改 ComfyUI 或该扩展的任何文件），使计算图真正执行 INT8 载荷。Float pack 走原路径不变 —— 没有 ConvRot INT8 sidecar 时，打补丁后的类与原类逐位一致。

### 3. 注意事项

- ComfyUI 核心（`comfy/`、`execution.py`）未被修改。运行时补丁仅在内存中替换 IP-Adapter 扩展的类。
- Float pack 走原路径不变。
- ConvRot INT8 pack 必须声明 `comfy_quant`，且 `format == int8_tensorwise`、`convrot == true`；其它格式会被显式 `RuntimeError` 拒绝，避免静默地把 codes 当作 float 计算。
- 模型只从 `ipadapter_dir` 指定的文件夹加载。
