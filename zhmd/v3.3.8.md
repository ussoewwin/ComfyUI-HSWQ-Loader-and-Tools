## 1. 为什么需要该功能

### 1.1 Krea2 特有的 VRAM 问题

Krea2 自带一个**体积很大的文本编码器（TE）**。在常规 ComfyUI 图中，TE 只在 `CLIPTextEncode` 阶段运行一次，把提示词转换为 `CONDITIONING`。在那之后，采样循环已经不再需要 TE 张量——采样期间与采样之后消耗 VRAM 的是扩散模型（DiT）与 VAE。

然而，ComfyUI 的模型管理器会让 TE 继续常驻在 `current_loaded_models` 中。在 Krea2 的运行里，常驻的 TE 与 DiT 可能在整个采样步骤中**同时驻留于 GPU**。在显存紧张的显卡上，正是这种共存把运行推入显存不足（OOM），或者迫使动态加载器反复抖动（不断加载 / 卸载 DiT），因而变慢。

Krea2 的参考**基准脚本**通过在采样前显式地把文本编码器移到 CPU 来回避这一点：

```python
clip.cond_stage_model.cpu()   # bench: free the TE before sampling
```

这一行就是全部思路：提示词编码完成后，把 TE 从 GPU 上卸下，让 DiT 拿到基准脚本所假定的 VRAM。HSWQ Sampler 此前没有等价处理，因此 HSWQ 图在 Krea2 上无法达到**与基准一致的 VRAM**。本功能填补了这一差距。

### 1.2 为什么必须做成开关，并且限定 Krea2

只有在以下条件同时成立时，释放 TE 才是安全的：

* 工作流在采样之后**不会**再次编码（常见情形：编码 → 采样 → VAE 解码），并且
* 模型确实**就是** Krea2。

对其他任何架构而言，同样的“释放 CLIP”动作要么无用，要么有害：

* **Z Image / Lumina2**、**Flux**、**SDXL**、**Qwen**、**WAN** 同样封装了类似 CLIP 的编码器。在图的中途卸载*它们的*编码器，会破坏那些本来就需要编码器常驻的无关工作流（多趟、重新编码、refiner）。
* **全局**缓存清扫（`soft_empty_cache` / `empty_cache` / `unload_all_models`）会波及共享同一 CUDA 缓存分配器的每一个工作流，因此可能驱逐*另一个*正在运行的图仍然需要的张量。

所以本功能被刻意做得很窄：

1. 它**默认关闭**，并以显式的选择性启用控件暴露出来。
2. 只有当 **MODEL 输入是 Krea2 扩散模型**时才会运行。
3. 只会卸载 **Krea2 的文本编码器**（依据精确的模块标识，而不是名称来判定）。
4. **绝不**调用全局分配器操作——它通过把 patcher 从 `current_loaded_models` 中移除、交由 Python 的引用计数释放，来释放 TE 张量。

### 1.3 为什么判定必须被加固（修复链）

最初的版本（`b135601`）证明了 VRAM 的节省，但对 Krea2 / TE 的判定过于宽松。后续提交逐一消除了该分支可能在错误模型上触发、或误读开关的每一种途径：

* `a1812c3` —— 严格限定到 Krea2，并**加固开关的读取**，使得错位的旧工作流无法悄悄把它打开。
* `3c25505` —— 不再**凭类名猜测**。改为依据加载器的**加载期标记**以及 ComfyUI 自身的架构检测来判定 Krea2；依据**精确的模块标识**（`comfy.text_encoders.krea2`）来判定 TE。
* `3d116ed` —— 彻底移除 `soft_empty_cache`，以实现与其他工作流的**完全分支隔离**。
* `3fe5c0b` —— 在 UI 上暴露适用范围：控件显示为 **`clip_perfect_offload (Krea2 only)`**，使该限制直接呈现在节点上，而不仅仅写在提示文本里。

### 1.4 为什么把 None 对策链也纳入其中

TE offload 的实现与所报告的采样后故障共享同一条执行路径：`HSWQSampler.sample()` 返回一个 `LATENT`，随后由 VAE 解码节点消费它。丢失的采样结果会产生 `samples=None`，而原版 `VAEDecode` / `VAEDecodeTiled` 会立即索引 `samples["samples"]`，从而在采样已经结束之后抛出 `TypeError: 'NoneType' object is not subscriptable`。因此完整的工作包含采样器回退、专用的分块解码器、全局 None 守卫，以及启用该守卫的包注册。省略这些文件，就等于省略了在 TE offload 提交之后加入的真正故障对策。

### `patches/comfy_quant_int8.py` — 修改的代码（diff）

**这项变更做了什么。** 这个文件正是 HSWQ INT8 UNet 加载器构建扩散模型的地方，因此它是唯一能在加载期可靠看到 Krea2 模型的位置。该变更加入了一套小而自洽的打标机制：

* **`KREA2_MODEL_FLAG = "_hswq_is_krea2"`** —— 唯一且规范的属性名，只定义一次，这样加载器与采样器就不会在标记的拼写上产生分歧。
* **`model_is_krea2(model)`** —— 只读判定函数。它遍历常见的包装层（`model`、`.model`、`.diffusion_model`、`.patcher`），只要其中任何一层带有该标记就返回 `True`。它从不凭类名猜测，只报告被显式打上的标记。
* **`tag_krea2_model(model)`** —— 写入函数。在加载期，它依据模型配置 / 架构判断这是否为 Krea2；若是，则把 `KREA2_MODEL_FLAG = True` 打到模型（以及存在的内层模块）上并返回 `True`。**只在加载时判定一次**，避免每次采样都重跑脆弱的启发式逻辑。
* **调用点** —— `if tag_krea2_model(model):` 在 HSWQ INT8 UNet 加载器内、模型对象刚生成之后被调用，因此该加载器产出的每个模型在抵达采样器之前都已被正确标注。

**为什么必须这么做。** TE offload 功能只能对 Krea2 生效，并且必须能够**可靠地**判断"这是 Krea2"，而不是靠检查会随 ComfyUI 版本变化的类名。在加载期打上一个布尔标记，为采样器提供了廉价、确定且向前兼容的信号。

### `nodes/hswq_sampler.py` — 修改的代码（diff）

**这项变更做了什么。** 这是执行采样的节点，也是 offload 真正发生的地方。该 diff 加入了三部分内容：

* **导入** —— `comfy.model_management as _mm`（用于把模块移入 / 移出 VRAM）以及来自 `patches/comfy_quant_int8.py` 的 `KREA2_MODEL_FLAG`（用于读取上文所述的加载期标记）。直接导入该标记而不是重新推导，能保持单一事实来源。
* **判定与 offload 辅助函数**
  * `_is_krea2_diffusion_model(model)` —— 与 `model_is_krea2` 对应：仅当扩散模型带有 `KREA2_MODEL_FLAG` 时返回 `True`，因此 offload 路径由这个可靠标记把关。
  * `_is_krea2_text_encoder(clip)` —— 识别 Krea2 的文本编码器对象，使我们 offload 的是*正确的* CLIP，在多模型工作流中绝不会碰到无关的编码器。
  * `_offload_requested(...)` —— 解析用户是否真的启用了开关（见下文的控件变更）**并且**模型是否为 Krea2，只有两者同时成立才返回 `True`。
  * `_offload_loaded_clips(...)` —— 机械执行部分：找到已加载的 Krea2 CLIP 模块，并请求 `comfy.model_management` 把它移出 GPU，从而在 UNet 采样开始前释放 VRAM。它写得很防御性，因此 offload 失败只会退化为"不 offload"，绝不会崩溃。
* **可选 UI 控件** —— `INPUT_TYPES` 条目被暴露为 **`clip_perfect_offload (Krea2 only)`**，因此标签本身就告诉用户该开关是 Krea2 专用的。
* **`sample()` 重写** —— 用 `kwargs.get` 读取开关，**同时**接受新标签 `"clip_perfect_offload (Krea2 only)"` 与旧键 `"clip_perfect_offload"`，使已保存的旧工作流继续可用。当请求 offload 时，它会卸载 Krea2 CLIP、运行 `common_ksampler`，并且——这一点至关重要——被包裹起来，使得若采样未返回可用结果，就发出一个**有效的回退 LATENT**（克隆的输入 latent，或形状正确的零张量）而非 `None`。这是 None 对策中属于采样器一侧的那一半。

**为什么必须这么做。** Krea2 的文本编码器很大；在 UNet 采样期间让它常驻会浪费扩散模型所需的 VRAM。只有当模型确实是 Krea2 且用户主动选择时才卸载它，可以安全地把 VRAM 还回来，而回退机制则保证该节点的 LATENT 输出永远不会是 `None`。

```python
Never raises on a bad LATENT input. When the upstream sampler drops its result

from collections.abc import Mapping

import torch

logger = logging.getLogger(__name__)

                            "decode at a time."
                        ),
                        "advanced": True,
                    },
                ),
                "temporal_overlap": (
                    "INT",
                    {
                        "default": 8,
                        "min": 4,
                        "max": 4096,
                        "step": 4,

                            "Only used for video VAEs: Amount of frames to "
                            "overlap."
                        ),
                        "advanced": True,
                    },

    FUNCTION = "decode"
    CATEGORY = "HSWQ/model/latent"
    TITLE = "HSWQ VAE Decode Tiled"

    def _recover_latent(samples):

        latent = None
        if isinstance(samples, Mapping):
            latent = samples.get("samples")
        elif isinstance(samples, torch.Tensor):
            latent = samples

        if isinstance(latent, torch.Tensor) and latent.numel() > 0:
            return latent

        # Upstream dropped the result. Build a small zero latent so decode still
        # runs and the graph completes with a black image instead of crashing.
        logger.warning(
            "[HSWQ VAE Decode Tiled] LATENT was missing/None; substituting a "
            "zero latent so the graph completes (output will be blank)."
        )
        return torch.zeros((1, 4, 64, 64), dtype=torch.float32)

        self,
        vae,
        samples,
        tile_size,
        overlap=64,
        temporal_size=64,
        temporal_overlap=8,

        if tile_size < overlap * 4:
            overlap = tile_size // 4
        if temporal_size < temporal_overlap * 2:
            temporal_overlap = temporal_size // 2

        try:

            temporal_compression = None

        if temporal_compression is not None:
            temporal_size = max(2, temporal_size // temporal_compression)
            temporal_overlap = max(
                1,
                min(temporal_size // 2, temporal_overlap // temporal_compression),
            )
        else:
            temporal_size = None
            temporal_overlap = None

        compression = vae.spacial_compression_decode()
        images = vae.decode_tiled(
            latent,
            tile_x=tile_size // compression,
            tile_y=tile_size // compression,
            overlap=overlap // compression,
            tile_t=temporal_size,
            overlap_t=temporal_overlap,
        )
        if len(images.shape) == 5:
            images = images.reshape(
                -1,
                images.shape[-3],
                images.shape[-2],
                images.shape[-1],
            )
```

### `patches/vae_decode_none_guard.py` — 新增文件（完整）

**这个文件是什么。** 全局 None 防护。它不要求用户更换节点，而是在运行时对**原版** `VAEDecode` / `VAEDecodeTiled` 节点以及底层 `comfy.sd.VAE` 的解码方法打猴子补丁，使图中*任何*解码都受到保护 —— 包括第三方自定义节点执行的解码。

**它是如何工作的，逐部分说明。**
* `apply_vae_decode_none_guard(deep=...)` —— 由 `__init__.py` 调用的入口点。当 `deep=True` 时，它会完整扫描 `NODE_CLASS_MAPPINGS`，为每一个具备解码能力的节点打补丁。
* `_prepare(args, kwargs)` —— 规范化调用：定位 `vae`（位置参数 `args[0]` 或关键字参数）与 `samples`（位置参数 `args[1]` 或关键字参数），并在传入 latent 为 `None` / 无效时重建一个有效的 `{"samples": <Tensor>}`。正是这一步阻止了 `samples["samples"]` 去索引 `None`。
* `_usable_tensor(t)` —— 校验候选 latent 张量。对于**嵌套（nested）**张量，它会有意直接返回 `True` 而不调用 `numel()`（该方法在嵌套张量上会抛异常），从而避免二次崩溃。
* `_blank_image(vae, ...)` —— 作为最后手段构造一张尺寸正确的空白图像，并用 `if vae is not None:` 加以保护，使缺失的 VAE 本身不会引发异常。
* 最近可用 latent 的恢复 —— 该防护会记住最后一个有效 latent，因此在可能的情况下恢复真实内容而非空白画面。
* `_install_prompt_hook()` —— 包装 prompt 执行器的 `execute` / `execute_async`，使 `deep=True` 的扫描在**每次 prompt 之前**运行。配合 `_SEEN_NAMES` 集合，新注册 / 晚注册的节点会被增量地纳入，因此延迟加载的自定义节点同样会被打上补丁。

**为什么必须这么做。** 原版 `VAEDecodeTiled.decode` 执行的是 `images = vae.decode_tiled(samples["samples"], ...)`。只要任一上游节点产出 `None`，这一行就会抛出 `TypeError: 'NoneType' object is not subscriptable`。在这一层打补丁，可以把故障吸收在*本*扩展包内部 —— 正是"所有 None 由我们自己碾碎"的要求 —— 而无论坏 latent 是由哪个节点产生的。

```python
                    _remember_result(result)
                except Exception:
                    logger.debug("[HSWQ None-guard] cache skipped", exc_info=True)
            return result

    setattr(guarded, _GUARD_MARK, True)
    return guarded


def _takes_latent_samples(node_cls) -> bool:
    input_types = getattr(node_cls, "INPUT_TYPES", None)
    if input_types is None:
        return False
    try:
        spec = input_types()
    except Exception:
        return False
    if not isinstance(spec, Mapping):
        return False
    entry = (spec.get("required") or {}).get("samples")
    if entry is None:
        entry = (spec.get("optional") or {}).get("samples")
    if isinstance(entry, (list, tuple)) and entry:
        return entry[0] == "LATENT"
    return False


def _return_types(node_cls) -> tuple:
    return tuple(getattr(node_cls, "RETURN_TYPES", ()) or ())


def _patch_node(node_cls, name: str, sanitize: bool = True) -> bool:
    if node_cls is None or not isinstance(node_cls, type):
        return False
    func_name = getattr(node_cls, "FUNCTION", None)
    if not isinstance(func_name, str):
        return False
    original = node_cls.__dict__.get(func_name)
    if original is None:
        original = getattr(node_cls, func_name, None)
    # classmethod / staticmethod entry points would lose their binding.
    if not isinstance(original, types.FunctionType):
        return False
    if getattr(original, _GUARD_MARK, False):
        return False

    returns = _return_types(node_cls)
    setattr(
        node_cls,
        func_name,
        _wrap(
            original,
            name,
            sanitize=sanitize,
            absorb=returns == ("IMAGE",),
            remember="LATENT" in returns,
        ),
    )
    return True


def _patch_vae_class() -> bool:
    """Guard ``comfy.sd.VAE.decode`` / ``decode_tiled`` against empty latents."""
    try:
        import comfy.sd as comfy_sd
    except Exception as e:
        logger.debug("[HSWQ None-guard] comfy.sd import failed: %s", e)
        return False

    vae_cls = getattr(comfy_sd, "VAE", None)
    if vae_cls is None:
        return False

    patched = []
    for method_name in ("decode", "decode_tiled"):
        original = getattr(vae_cls, method_name, None)
        if original is None or getattr(original, _GUARD_MARK, False):
            continue

        def make(original=original, method_name=method_name):
            def guarded(self, samples_in, *args, **kwargs):
                if not _usable_tensor(samples_in):
                    extracted = _extract_latent(samples_in)
                    if extracted is None:
                        recovered = _recovered_latent()
                        if recovered is not None:
                            logger.warning(
                                "[HSWQ None-guard] VAE.%s got an empty latent; "
                                "using the last valid latent instead.",
                                method_name,
                            )
                            extracted = recovered["samples"]
                        else:
                            logger.warning(
                                "[HSWQ None-guard] VAE.%s got an empty latent; "
                                "substituting zeros.",
                                method_name,
                            )
                            extracted = _blank_latent(self)
                    samples_in = extracted
                return original(self, samples_in, *args, **kwargs)

            setattr(guarded, _GUARD_MARK, True)
            return guarded

        setattr(vae_cls, method_name, make())
        patched.append(method_name)

    return bool(patched)


def _install_prompt_hook() -> bool:
    """Re-apply the guard per prompt so late class swaps stay covered."""
    try:
        import execution
    except Exception as e:
        logger.debug("[HSWQ None-guard] execution import failed: %s", e)
        return False

    executor = getattr(execution, "PromptExecutor", None)
    if executor is None:
        return False

    installed = False
    for method_name in ("execute", "execute_async"):
        original = executor.__dict__.get(method_name)
        if not isinstance(original, types.FunctionType):
            continue
        if getattr(original, _GUARD_MARK, False):
            continue

        def make(original=original):
            def execute(self, *args, **kwargs):
                try:
                    apply_vae_decode_none_guard(deep=True)
                except Exception:
                    logger.debug("[HSWQ None-guard] re-apply skipped", exc_info=True)
                return original(self, *args, **kwargs)

            setattr(execute, _GUARD_MARK, True)
            return execute

        setattr(executor, method_name, make())
        installed = True

    return installed


def apply_vae_decode_none_guard(deep: bool = False) -> bool:
    """Patch every LATENT path. Safe to call repeatedly.

    ``deep`` inspects every node name not seen yet; it is used from the prompt
    hook because at import time other packs may not be registered yet.
    """
    try:
        import nodes as comfy_nodes
    except Exception as e:
        logger.debug("[HSWQ None-guard] nodes import failed: %s", e)
        return False

    patched = []
    mappings = getattr(comfy_nodes, "NODE_CLASS_MAPPINGS", None)
    if not isinstance(mappings, Mapping):
        mappings = {}

    for name in _STOCK_NODES:
        if _patch_node(getattr(comfy_nodes, name, None), name):
            patched.append(name)
            _PATCHED_NAMES.add(name)

    if deep:
        # New names only, plus the ones already wrapped (their class may have
        # been replaced by another pack since the last prompt).
        fresh = [n for n in mappings if n not in _SEEN_NAMES]
        candidates = [(n, mappings.get(n), True) for n in fresh]
        candidates += [(n, mappings.get(n), False) for n in sorted(_PATCHED_NAMES)]
    else:
        candidates = [(n, mappings.get(n), False) for n in sorted(_PATCHED_NAMES)]

    for name, node_cls, is_fresh in candidates:
        try:
            if is_fresh:
                _SEEN_NAMES.add(name)
            if node_cls is None:
                continue
            returns = _return_types(node_cls)
            produces_latent = "LATENT" in returns
            decodes_latent = "IMAGE" in returns and (
                not is_fresh or _takes_latent_samples(node_cls)
            )
            if not (produces_latent or decodes_latent):
                continue
            if _patch_node(node_cls, str(name), sanitize=decodes_latent):
                patched.append(str(name))
                _PATCHED_NAMES.add(str(name))
        except Exception:
            logger.debug("[HSWQ None-guard] skip %s", name, exc_info=True)

    if _patch_vae_class():
        patched.append("comfy.sd.VAE")

    _install_prompt_hook()

    if patched:
        logger.info(
            "[HSWQ] LATENT None-guard armed on %d entry point(s): %s",
            len(patched),
            ", ".join(patched[:12]) + (" ..." if len(patched) > 12 else ""),
        )
    return bool(patched)
```

## 4. 代码的含义

### 4.1 加载期打标 → 读取，而非猜测（`patches/comfy_quant_int8.py`）

* `KREA2_MODEL_FLAG = "_hswq_is_krea2"` —— 加载器（写入方）与采样器节点（读取方）共享的唯一属性名。
* `model_is_krea2(model)` —— **判定**。它按以下顺序采信：已存在的标记；ComfyUI 自身的 `unet_config["image_model"] == "krea2"`（由 `model_detection` 直接依据 state dict 写入）；以及精确的类型名 `supported_models.Krea2` / `model_base.Krea2`。对类名或文件名**不做任何子串匹配**，因此重命名 checkpoint 或碰上相似名称都不可能翻转判定结果。
* `tag_krea2_model(model)` —— 把判定结果同时盖到**外层** `ModelPatcher` 与**内层** `BaseModel` 上。内层之所以重要，是因为 `ModelPatcher` 的克隆会重新包裹同一个内层模型；若标记只存在于外层 patcher，克隆就会悄悄丢失它。
* 在加载期调用意味着昂贵的架构检测只发生**一次**（加载时），之后每个节点只需读取一个布尔值。

### 4.2 节点内两项彼此独立的身份检查（`nodes/hswq_sampler.py`）

* `_is_krea2_diffusion_model(model)` —— 回答**"我正在采样的 MODEL 是不是 Krea2 DiT？"**。它先读取加载器标记，再回退到与加载器相同的架构检测身份判据。若结果为 False，则永远不会进入卸载分支 —— 所有非 Krea2 架构（Z Image、Flux、SDXL、Qwen、WAN）都在此处返回。
* `_is_krea2_text_encoder(patcher)` —— 回答**"这个已加载的编码器是不是 Krea2 TE？"**。仅凭 `is_clip` 并不充分，因为每个 CLIP 包装器都会设置它；决定性的检验是：编码器对象之一（`patcher`、`cond_stage_model`、`clip_model`、`transformer`、`text_model`）定义于精确模块 `comfy.text_encoders.krea2`。Z Image / Flux / SDXL 的 TE 永远不会匹配，因此永远不会被卸载。

这两项检查是**有意彼此独立**的：只有当模型是 Krea2 *且*确实驻留着一个 Krea2 TE 时，卸载才会执行。任一条件不成立，整个流程就是安全的空操作。

### 4.3 严格的开关读取（`_offload_requested`）

ComfyUI 在保存的工作流中**按位置**存储 widget 值。若某个旧工作流是在该 widget 存在之前保存的，前端可能用相邻的值（例如 `denoise = 1.0`）填入这个槽位。天真的 `if value:` 会把 `1.0` 判为真值并触发卸载，而 UI 上开关仍显示为**关闭**。因此 `_offload_requested` **只**接受真正的 Python `bool`：`True` 启用，`False` / `None` 禁用，其他任何值一律拒绝并作为错位记录到日志。这也是该 widget 被声明为**可选（optional）**的原因 —— 以免改变既有 widget 的位置顺序。

`sample()` 的闸门先读取**新**键 `"clip_perfect_offload (Krea2 only)"`，再回退到**旧**键 `"clip_perfect_offload"`，因此在 `3fe5c0b` 重命名之前保存的工作流仍能映射到同一个开关。

### 4.4 卸载序列，以及它为何在全局层面被隔离（`_offload_loaded_clips`）

该序列复刻了基准脚本的做法，但严格限定在 Krea2 范围内：

1. 只收集当前位于 `current_loaded_models` 中的 **Krea2** TE patcher（按 `id` 去重）。
2. 如果一个都没有，就**什么都不做** —— 关键在于它*不会*回退去做全局缓存清扫。
3. 对每一个 Krea2 TE：
   * `cond_stage_model.cpu()` —— 基准脚本的动作，把 TE 权重移出 GPU。
   * `unload_model_and_clones(patcher, unload_additional_models=False)` —— 从已加载集合中精确移除该 TE patcher 及其自身的克隆。`unload_additional_models=False` 保证 **DiT、VAE、ControlNet 以及其他所有模型继续驻留**；只有 TE 离开。
   * 如果该调用抛出异常，则由**仅限 TE** 的回退路径把这一个 patcher 从 `current_loaded_models` 弹出并卸载。

贯穿整个函数的规则是：**绝不调用任何全局分配器操作**（`soft_empty_cache`、`empty_cache`、`unload_all_models`）。这些操作作用于共享的 CUDA 缓存分配器，会波及在同一 GPU 上运行的*其他*工作流。取而代之的是，通过把 patcher 移出 `current_loaded_models` 并交由 Python 引用计数释放来回收 TE 张量。这就是 `3d116ed` 所强制的"完全分支隔离"：Krea2 卸载绝不可能干扰并发的 Z Image / Flux / SDXL 图。

### 4.5 UI 作用域标注（`3fe5c0b`）

widget 的键就是**显示出来的标签**。把它改名为 `clip_perfect_offload (Krea2 only)`，等于把作用域写在节点表面上 —— 与 HSWQ Save Image 节点上既有的 `quality (JPG only)` 约定保持一致 —— 使用户无需悬停查看 tooltip 也能看到 Krea2 限制。向后兼容性由 4.3 中所述的双键 `kwargs.get` 读取来保证。

### 4.6 失败时的行为

每一步都被包裹起来，使该功能**绝不可能破坏一次运行**：

* 若模型不是 Krea2，闸门记录日志并跳过（`clip_perfect_offload ignored: MODEL is not Krea2`）。
* 若任一卸载步骤抛出异常，异常会被捕获并记录，采样照常继续。
* 错位的开关值一律按 OFF 处理。

因此该卸载在 Krea2 上是纯粹的尽力而为式 VRAM 优化：适用时达到与基准一致的 VRAM，其他所有情况下都是惰性的空操作。

### 4.7 采样结果回退（`nodes/hswq_sampler.py`）

对 `common_ksampler` 的调用被吸收在扩展包内部。合法结果必须是一个 tuple / list，其首项为包含非 None `samples` 张量的 LATENT 字典。若采样抛出异常或丢失结果，节点会克隆输入 latent；若输入也不可用，则创建一个最小的零张量。这可防止 HSWQ Sampler 自身吐出一个裸的 `None`。

### 4.8 专用分块解码器（`nodes/hswq_vae_decode_tiled.py`）

`HSWQVAEDecodeTiled` 既接受普通的 LATENT 字典，也直接接受张量。缺失的载荷会被替换为 `(1, 4, 64, 64)` 的零 latent，随后再进行常规的空间 / 时间分块转换。这为工作流提供了一个明确归属于 HSWQ 的解码器，即便上游丢掉了 LATENT，其输出约定仍然是 `IMAGE`。

### 4.9 全局 None 防护（`patches/vae_decode_none_guard.py`）

该全局防护具有四个彼此独立的层次：

1. 产出 LATENT 的节点会把最新的可用 latent 缓存在 CPU 上。
2. 每一个 LATENT→IMAGE 节点都会被包装，包括后期注册的第三方节点。
3. `comfy.sd.VAE.decode` 与 `decode_tiled` 会在节点包装层之下净化空张量输入。
4. `PromptExecutor.execute` 与 `execute_async` 会在每次 prompt 之前重新武装扫描，覆盖在扩展包导入之后才被替换的类。

恢复时优先采用真实的缓存 latent。只有在从未观察到任何可用 latent 时，才会以零替代。产出 IMAGE 的解码失败会被吸收，返回一张形状正确的空白图像，而不是中止 prompt。嵌套张量会绕过 `numel()`，因为该操作对嵌套张量未定义。

### 4.10 扩展包注册（`__init__.py`）

扩展包导入时会调用 `apply_vae_decode_none_guard()`，并以 warning / exception 级别上报武装失败，而不是默默吞掉。同一文件还在 `NODE_CLASS_MAPPINGS` 中注册了 `HSWQVAEDecodeTiled`。这些行是必不可少的：只创建补丁文件却不导入并注册它们，会使保护处于未生效状态。

## 5. 总结

* **是什么**：HSWQ Sampler 上一个需手动开启的 `clip_perfect_offload (Krea2 only)` 开关，在采样前释放 Krea2 文本编码器，复现基准脚本 `clip.cond_stage_model.cpu()` 的 VRAM 行为。
* **为什么**：驻留的 Krea2 TE 在采样期间与 DiT 共存，把显存紧张的显卡推向 OOM / 加载器颠簸；基准脚本通过卸载 TE 规避了这一点，而 HSWQ 图此前没有等价手段。
* **如何保持安全**：两项彼此独立、不依赖名称的身份检查（Krea2 DiT 通过加载期标记 + 架构检测；Krea2 TE 通过精确的 `comfy.text_encoders.krea2` 模块身份）、严格的布尔开关读取、仅卸载 TE 而让其他所有模型继续驻留，以及**零**全局分配器操作，因此绝不触碰任何其他工作流。
* **文件**：三个以改动形式展示的已修改源文件（`__init__.py`、`patches/comfy_quant_int8.py`、`nodes/hswq_sampler.py`）与两个完整展示的新增源文件（`nodes/hswq_vae_decode_tiled.py`、`patches/vae_decode_none_guard.py`）。
