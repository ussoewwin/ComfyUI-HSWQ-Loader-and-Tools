## ① 许可清理 — 本仓库仅为 GPL-3.0

### 原先的问题

残留的 **Apache-2.0** 表述与重复许可文件（`LICENCE.txt`）与真实项目许可（`LICENSE` / `pyproject.toml` 中的 **GPL-3.0**）冲突，读者可能误认为本加载器包为 Apache 或错误的双许可。

### 变更（`43a7f17`）

| 路径 | 变更 |
|------|--------|
| `LICENCE.txt` | **删除**（Apache-2.0 残留，201 行） |
| `pyproject.toml` | `license` / classifiers 对齐为 **GPL-3.0** |
| `README.md` / `zhmd/README.md` | 重写 License 节 |

### 正确的许可划分（重要）

| 作品 | 许可 | 位置 |
|------|---------|--------|
| **本仓库**（ComfyUI 加载器 / 工具） | **GPL-3.0** | `LICENSE`、`pyproject.toml` |
| **上游 HSWQ**（量化脚本 / 方法文档） | **AGPL-3.0** | [Hybrid-Sensitivity-Weighted-Quantization](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization) — **独立仓库**；其 AGPL **不能**替代本包的 GPL |

README 现明确：HSWQ（量化方法）为 ussoewwin 原创作品，许可为 **AGPL-3.0**；本 ComfyUI 加载器包为**相关但独立**的仓库，许可为 **GPL-3.0**。

## ② 来源说明 — USDU / Torch Compile / Batched Detailer

### 目标

以 **based-on / developed-from** 记录第三方 GPL 作品，**不使用** “copied from” 类措辞，同时保留：

- 版权声明
- GPL 传染 / 相同许可义务
- 明确：当辅助代码已内嵌时，**运行时不必安装原包**

### USDU（`22e834b`，License 节）

**HSWQ Ultimate SD Upscale** 基于 [ComfyUI_UltimateSDUpscale](https://github.com/ssitu/ComfyUI_UltimateSDUpscale)（ssitu，GPL-3.0）开发，并加入 HSWQ / FP8 / torch.compile / Auto scale 等原创改进。内嵌 `usdu_bundle` **并不**免除对 ssitu 原作的 GPL 义务。运行时**不需要**单独安装 UltimateSDUpscale 包。

### Torch Compile（`01cebd3`、`22e834b`）

**HSWQ Torch Compile** 基于 [ComfyUI-KJNodes](https://github.com/kijai/ComfyUI-KJNodes) `TorchCompileModelAdvanced`（kijai，GPL-3.0）开发，并加入 HSWQ / USDU / Distorch / Windows inductor 加固。运行时调用 ComfyUI 核心 `comfy_api.torch_helpers.set_torch_compile_wrapper`，**不** import KJNodes 包；这**不**免除对 KJNodes 原作的版权 / GPL 义务。KJ 来源说明**不**适用于 HSWQ 量化方法本身。

### Batched Detailer（`6611cd1`，随后 `f3c4b6c`）

**HSWQ Batched Detailer (SEGS)** 基于 [ComfyUI-Impact-Pack](https://github.com/ltdrdata/ComfyUI-Impact-Pack) Detailer (SEGS) / DetailerForEach（ltdrdata，GPL-3.0）开发，并加入原创改进，**尤其用于保持 HSWQ 量化 UNet 可用**（INT8 / NVFP4 ConvRot、Dynamic VRAM、QuantizedTensor 路径），同时保留 Impact Pack SEGS 接口。

## ③ Batched Detailer — 无 Impact Pack 运行时 import（`f3c4b6c`）

### 原先的问题

节点此前在运行时 `import impact.*`，即使本包在 USDU / Torch Compile 上已追求独立，Impact Pack 仍是**硬依赖**。

### 变更

| 路径 | 作用 |
|------|------|
| `nodes/batched_detailer_lib/__init__.py` | 再导出 `SEG`、`utils`、`core`、`impact_sampling`、`wildcards` |
| `nodes/batched_detailer_lib/utils.py` | SEGS 辅助（crop / paste 等） |
| `nodes/batched_detailer_lib/core.py` | batched 循环使用的 Detailer 核心片段 |
| `nodes/batched_detailer_lib/sampling.py` | Detailer 使用的 KSampler 包装路径 |
| `nodes/batched_detailer_lib/wildcards.py` | 通配符处理（必要时 identity `process()`） |
| `nodes/batched_detailer_lib/NOTICE` | 归属声明 |
| `nodes/batched_detailer_lib/IMPACT_PACK_LICENSE.txt` | Impact Pack 来源用的完整 GPL-3.0 文本 |
| `nodes/hswq_batched_detailer.py` | **仅** import `.batched_detailer_lib` — **无** `impact.*` |
| `README.md` / `zhmd/README.md` | 独立运行 + 来源说明 |

### Import 形态（之后）

```python
from .batched_detailer_lib import (
    SEG,
    impact_sampling,
    utils,
    wildcards,
)
from .batched_detailer_lib import core
```

### 运行时 vs 工作流接线

- **运行时**：加载本节点**不需要**安装 Impact Pack 包。
- **工作流**：仍可从 Impact 检测器（或任意 SEGS 生产者）接入 SEGS；那是可选接线，不是 import 依赖。
- 内嵌 `nodes/batched_detailer_lib/` **并不**免除对 Impact Pack 原作的 GPL 义务。

## ④ HSWQ Torch Compile — 始终按块编译（`d0f1301`）

### 变更

| 项目 | 之前（v3.3.6 UI） | 之后（v3.3.7） |
|------|--------------------|----------------|
| `compile_transformer_blocks_only` | BOOLEAN 输入（默认 `True`） | 从 `INPUT_TYPES` **移除** |
| 块键收集 | 仅开关为 ON 时 | **始终** `_collect_block_keys(diffusion_model)` |
| 回退 | 开关 OFF / 空列表时整模 `diffusion_model` | 无已知块时同样回退：`["diffusion_model"]` |
| 旧工作流 | — | 经 `**_kwargs` 忽略多余参数，带已删控件的旧图不崩溃 |

### 行为说明

原默认已是 **ON**。v3.3.7 将其定为唯一路径：按已知 transformer block 容器编译；若找不到则告警并编译整个 `diffusion_model`。
