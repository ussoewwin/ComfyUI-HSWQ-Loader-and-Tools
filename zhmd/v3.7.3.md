# ComfyUI-HSWQ-Loader-and-Tools v3.7.3

## 概述

**为 SAM3（Segment Anything 3）检查点新增的加载器节点，支持 ConvRot INT8 与 CLIP 输出。** 之前的版本中 SAM3 模型作为节点存在于 HSWQ 量化包内，但从未作为加载器节点被文档化。v3.7.3 将其以一等加载器节点的形式发布与文档化，可从任意文件夹加载，并将检查点的文本编码器作为 `CLIP` 输出暴露出来。

`HSWQ SAM3 Loader (ConvRot INT8)` 以 8 位精度（`QuantizedTensor` / `TensorWiseINT8Layout`）直接将 ConvRot / TensorWise INT8 量化的 SAM3 检查点驻留 VRAM，并通过 `comfy_kitchen` 的 `int8_linear` 内核（带 `convrot` 在线激活旋转）执行。模型文件与加载来源文件夹分别选择（`sam3_name` + 必填的 `sam3_dir`）；文件下拉列表的选项会跟随 `sam3_dir` 中填写的文件夹。节点返回 SAM3 的 `model`（MODEL）以及检查点自带的文本编码器 `clip`（CLIP），可接入 `CLIPTextEncode` 做文本条件检测。

非 4 倍数维度的层（如 `K=2` 的 `boxRPB_embed_x`）会安全回退为 float 精度计算，而所有重型 backbone 与 transformer 块仍以加速的 INT8 Tensor Core 精度运行。非 INT8（FP16）SAM3 检查点正常加载（不附加 `MixedPrecisionOps`），因此同一节点对 INT8 与 FP16 pack 均可使用。

---

## 特性

- **SAM3 ConvRot INT8 pack 的直接替代加载器**：输入 `sam3_name` + `sam3_dir`，输出 `model`（MODEL）+ `clip`（CLIP）。
- **任意文件夹**：`sam3_dir` 为必填。模型只从该文件夹加载；留空会被拒绝，不会回退到其它文件夹。
- **CLIP 输出**：检查点的文本编码器以标准 ComfyUI `CLIP` 输出暴露，可直接接入 `CLIPTextEncode`（文本条件检测）。
- **自动硬件安全回退**：非对齐层（`K % 4 != 0`）以 float 精度计算，避免 cuBLAS INT8 GEMM 崩溃。
- **原生 INT8 VRAM 驻留**：权重保持 8 位（`TensorWiseINT8Layout`），显著降低显存占用。
- **无缝兼容 FP16**：FP16 SAM3 检查点以 ComfyUI 原生设置加载（不附加 `MixedPrecisionOps`，行为不变）。

---

## 兼容性

- **HSWQ SAM3 Detect**：加载器的 `model` 输出接入 `HSWQ SAM3 Detect`（分类 `HSWQ/Detection`），输出 masks / bbox / image。
- **ComfyUI 原生 SAM3 检测 / 跟踪节点**：`MODEL` 输出为标准 ComfyUI 模型。
- 仅支持由 [Hybrid-Sensitivity-Weighted-Quantization](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization) 生成的检查点；其他第三方 SAM3 量化包不在支持范围内。
