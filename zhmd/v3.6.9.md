# Release Notes（中文）：v3.6.9 为 ControlNet 模型提供量化 Conv2d 支持

版本 **v3.6.9** 为 **ControlNet 模型**启用量化 Conv2d：此前所有 ControlNet pack 的 conv 权重都停留在 FP16，压缩率因此被钉在低位；现在当 checkpoint 实际携带量化 Conv2d 层时，两个 HSWQ 加载器（`HSWQ ControlNet Loader` 与 `HSWQ Model Patch Loader`）会注入 HSWQ 量化 Conv2d（沿 in_channels 旋转、per-out-channel scale `[out, 1, 1, 1]`、在线激活旋转）。代码提交 `ede3f1b`。

---

### 1. 为什么 ControlNet pack 一直偏大

加载器此前只量化 2D `nn.Linear` 权重；ComfyUI 自带的 INT8 路径没有量化 Conv2d，所以 conv 权重全部留在 FP16。3×3 conv 密集的 SD1.5 ControlNet 正是被这一半主导：recolor pack 携带 **61 个 Conv2d 权重 = 440.57 MiB，占源文件的 63.9%**。Linear 半边单独压缩了 44%（248.1 MiB → 138.5 MiB），但整文件压缩率被钉在 **15.9%**（722,598,616 B → 607,603,903 B）。

### 2. 加载器现在做什么

量化 conv 的 pack 格式与 SD-UNet INT8 路径已有的格式相同：沿 in_channels 旋转、per-out-channel scale `[out, 1, 1, 1]`、`convrot_groupsize` 256，在线激活旋转由注入的 Conv2d 完成。

**检测**：两个加载器新增 `_has_int8_comfy_quant_conv2d()`，仅当某个 `int8_tensorwise` `comfy_quant` 层落在 4D 权重上时返回 True。量化层全为 Linear 的 pack 加载路径逐字节保持不变。

**注入**：对此类 checkpoint，加载器在 `_int8_quant_conv_scope()` **内部**构建 `custom_operations`，并显式应用 `_patch_ops_decode_and_conv()`。两步缺一不可：缺少显式 patch 时 ops 类上根本没有 Conv2d；缺少 scope 时注入会被跳过——两种情况下 int8 载荷都会被当作普通 float Conv2d 读取。实测按 float 读取时输出 cosine mean **−0.1142** / min **−0.1739**、rel L2 3.1e12——完全毁坏。因为静默漏掉是如此具有破坏性，patch 失败现在会**抛出并中止加载**，而不是静默通过。

### 3. 实测（SD1.5 recolor pack，61 个 Conv2d 量化 24 个）

| 实测项 | 数值 |
| :--- | :--- |
| pack 大小 | 607,603,903 B → **411,127,471 B**（**压缩率 43.1%**，−187.4 MiB） |
| 加载路由 | declared 77 / INT8 77 / **not applied 0** → `applies` |
| 与 source 的输出差（4 批，seed 42） | cosine mean **0.9996957** / min **0.9996680**，rel L2 max 0.0264760 |
| 仅 Linear 的 pack 对照 | cosine mean 0.9997190 / min 0.9996969（conv 一半以 2.3e-05 的 cosine 代价换来 187.4 MiB） |
| 256 项受入 gate | mean **0.999861** / min **0.999834** / p5 0.999849 → **PASS** |
| 渲染帧 | 1024×1024、12 steps、636 次 INT8 GEMM、latent 有限、目视检查无伪影 |

其余 37 个 conv 模块保持 FP16：它们的 in_channels 不能被 group size（256）整除，无法施加 Hadamard 旋转。

### 4. 兼容边界

- 仅 Linear 的 ControlNet pack 加载不变：既有 canny pack 实测 `applies` 53/53，与之前完全一致（回归实测）。
- Qwen-Image model patch 路径加载不变（602 张量，回归实测）。
- 不修改 ComfyUI core；只有携带量化 Conv2d 层的 checkpoint 才进入新路径。

提交为 `ede3f1b`（main），并已同步到 live 环境（LF 归一化后 repo/live 的 SHA-256 实测一致）。
