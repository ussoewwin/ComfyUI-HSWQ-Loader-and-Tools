## 1. 概述

v3.4.3 为 **Z Image / ZIT Hybrid ConvRot NVFP4** 模型新增了一条**可选的 Tensor Core（TC / W4A4）执行路径**。此前这些模型只能走 **Comfy parity** 路径 —— **W4A16**（NVFP4 权重 × fp16 激活，stock GEMM + online act rotate），它保留了 4-bit 权重压缩，但从不使用 FP4 Tensor Core。现在，只要带有逐层校准过的 `input_scale`，Linear 热路径就会切换到 **W4A4 TC**（NVFP4 权重 × 4-bit 旋转激活，走原始 `cublas_gemm_blockwise_fp4` GEMM），解锁真正的 Blackwell FP4 Tensor Core 吞吐。

该路径由**轨迹保真度验证**把关（确定性的逐步 latent 分歧对比）：TC 与 parity 的最终余弦为 **0.951 vs 0.952**（噪声级差异，**0 / 20 分叉**），因此 TC 不会带来系统性质量损失，同时获得 Tensor Core 加速。

## 2. parity 与 TC

| | parity（此前的默认） | TC（新的可选） |
|:---|:---|:---|
| 权重 | NVFP4（E2M1 + block scale） | NVFP4（E2M1 + block scale） |
| 激活 | fp16 | 4-bit NVFP4（旋转后，E2M1） |
| GEMM | stock `a @ w.T`（fp16） | 原始 `cublas_gemm_blockwise_fp4`（FP4） |
| Tensor Core FP4 | ✗ | ✓ |
| 前提条件 | — | 校准过的 `input_scale` |

parity 之所以是默认值，是因为 TC 需要激活量化缩放（`input_scale`），而早期发布的 checkpoint 并不携带它。把未校准的 checkpoint 强制走 TC 会导致质量崩溃（解码 SSIM ≈ 0.18）—— 这正是该路径设为可选并加以把关的原因。

## 3. `input_scale` 校准

- `input_scale = amax / 2688`，在**旋转域**（ConvRot 权重所存储的同一域）中测得。
- 由独立步骤 `Z_Image/calib_input_scale_nvfp4.py` 生成 —— 它采样模型逐层激活的 amax，并把 `*.input_scale` 键写入 `*_calib.safetensors` checkpoint。
- **测量而非搜索**：`input_scale` 是运行中的 absmax ÷ 2688，不是直方图 / 质量旋钮 —— 不存在逐层搜索。
- 加载器读取 checkpoint 中的 `*.input_scale` 来判定 TC 是否可用。

## 4. Loader 可选开关

- 优先级：**`HSWQ_ZI_FORCE_PARITY=1` > `HSWQ_ZI_FORCE_TC=1` > 自动检测 `*.input_scale`**。
- `checkpoint_has_input_scale()` 检测校准键；`zi_use_tensorcore()` 解析出最终模式。
- `HSWQ_ZI_FORCE_PARITY=1` 保持旧的 W4A16 行为；`HSWQ_ZI_FORCE_TC=1` 即使没有校准也强制走 W4A4（有意允许，但在未校准文件上会导致质量崩溃）。
- 警告过滤补丁（`_patch_load_model_weights_warnings()`）消除了 parity 路径此前不断刷屏的 `input_scale` / `comfy_quant` 加载警告。

## 5. 质量门 —— 轨迹分歧

- 工具：`benchmark/zi_convrot_nvfp4_traj_compare.py` —— 确定性的逐步 latent 轨迹对比器（`torch.backends.cudnn.deterministic = True`，固定 seed），测量最终 latent 余弦与参考值的差异。
- **分叉** = 单步余弦下降 > 0.05（偏离参考轨迹）。
- **同图**阈值 = 最终 cos ≥ 0.98。
- 结果（hybrid nv89，20 个 seed）：
  - TC：最终 cos 均值 **0.95137**，最小 0.86664，**0 / 20 分叉**
  - parity：最终 cos 均值 **0.95233**，最小 0.86509，**0 / 20 分叉**
  - → **TC ≈ parity**（均值差 0.001，噪声级）。
- 对照 —— 原生全 NVFP4（180 层，无 INT8 保护）：均值 0.90945，最小 0.60344，**1 / 20 分叉**（seed 12 偏离）。HSWQ 混合（对高影响层做 INT8 保护）消除了分叉。

## 6. 基准（test5 = moodyProMix nv90 配置）

- 解码 SSIM **0.9772**
- 显存 **12368 → 5935 MB（−52%）**，相对 FP16
- 耗时 **3.39 s vs 7.18 s（2.12×）**
- TC GEMM 命中 **2160**，反量化回退 **0**
- **160.5 TFLOPS**（约为 Blackwell FP4 峰值的 18%）
