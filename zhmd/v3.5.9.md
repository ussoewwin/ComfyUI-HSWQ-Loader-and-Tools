# v3.5.9 发布说明（中文）

## 概述

**v3.4.8 中删除的 SAM3 节点已恢复**，内容从 **v3.4.7 的 git 历史忠实复现**。恢复的节点共两个：

- **HSWQ SAM3 Loader (ConvRot INT8)** — `HSWQSAM3Loader` / `HSWQLoadConvRotINT8SAM3`
- **HSWQ SAM3 Detect** — `HSWQSAM3Detect`（输出 `masks` / `bboxes` / `image`）

本次恢复是对 tag `v3.4.7` 中节点文件的逐字节忠实检出，没有重写或"现代化"任何逻辑。唯一适配的部分是 `__init__.py` 中的节点注册块，按 v3.4.7 的相同位置（ControlNet Loader 注册之后）重新插入。

> **为什么只恢复节点和注册？** `patches/comfy_quant_int8.py` 中的 SAM3 INT8 加载补丁（`_patch_sam3_process_state_dict`、`_patch_load_state_dict_guess_config_int8`、`_patch_comfy_kitchen_int8_gemm_fallback`）**从未被删除**——自 v3.4.8 起它们一直在每个版本中随仓库发布并保持生效。v3.4.8 只删除了节点文件（`nodes/hswq_load_convrot_int8_sam3.py`、`nodes/hswq_sam3_detect.py`）、节点图片（`png/sam3.png`）和 `__init__.py` 注册块，因此本次恢复只涉及这些部分，不触碰其他任何内容。

## 恢复的节点

### HSWQ SAM3 Loader (ConvRot INT8)

面向 **ConvRot / TensorWise INT8 量化 SAM3（Segment Anything 3）检查点**的 ComfyUI 加载节点。以 8 位精度（`QuantizedTensor` / `TensorWiseINT8Layout`）将 SAM3 模型直接加载进 VRAM，并通过 `comfy_kitchen` 的高速 `int8_linear` 内核配合在线激活旋转（`convrot`）执行。

- **输入** `sam3_name`：ConvRot INT8 / 标准 SAM3 检查点（`.safetensors`），在 `diffusion_models` / `sams` / `detection` / `checkpoints` 目录中搜索
- **输出** `model`（`MODEL`）：标准 ComfyUI 模型，与 **HSWQ SAM3 Detect** 及原生 ComfyUI SAM3 节点兼容
- 检测 `int8_tensorwise` comfy_quant 元数据并自动附加 `MixedPrecisionOps`，使 Linear 层在 VRAM 中**保持真正的 INT8**
- 非 INT8 检查点按普通方式加载（不附加 MixedPrecisionOps）

### HSWQ SAM3 Detect

在已加载 SAM3 模型之上运行的文本/框/点提示检测节点。

- **输入**
  - `model`（`MODEL`）：SAM3 模型（来自 HSWQ SAM3 Loader 或 CheckpointLoaderSimple）
  - `image`（`IMAGE`）：输入图像（支持批处理）
  - `conditioning`（`CONDITIONING`，可选）：文本提示，例如 CLIPTextEncode 的 `"person"`
  - `bboxes`（`BBOXES`，可选）：在其中进行分割的框
  - `positive_coords` / `negative_coords`（`STRING`，可选）：点提示，JSON 格式 `[{"x": int, "y": int}, ...]`（像素坐标）
  - `threshold`（默认 `0.50`）：检测分数阈值
  - `refine_iterations`（默认 `2`）：SAM 解码器细化迭代次数（`0` = 原始检测器掩码）
  - `individual_masks`（默认 `false`）：输出每个目标的掩码而非并集
- **输出**
  - `masks`（`MASK`）：二值分割掩码
  - `bboxes`（`BBOXES`）：带分数的检测框
  - `image`（`IMAGE`）：直通的输入图像

包含针对非对齐层（例如 `K=2` 的 `boxRPB_embed_x`）的自动硬件安全回退：非 4 倍数维度动态反量化为浮点计算，而所有重量级的 backbone 和 transformer 块仍在加速的 INT8 Tensor Core 精度下运行。

两个节点均完全支持**标准 FP16 SAM3 检查点**（例如 `sam3.1_multiplex_fp16.safetensors`）：Loader 检测不到 `int8_tensorwise` 元数据时按原生设置加载，Detect 在 FP16 与 INT8 模型上的运行方式完全一致。

## 更新方法

通过 ComfyUI Manager 更新，或在 `custom_nodes/ComfyUI-HSWQ-Loader-and-Tools` 目录中直接拉取：
```bash
git pull
```
重启 ComfyUI 使更改生效。重启后，**HSWQ SAM3 Loader (ConvRot INT8)** 与 **HSWQ SAM3 Detect** 会重新出现在节点搜索菜单中。
