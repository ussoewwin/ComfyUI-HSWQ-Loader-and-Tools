# Release Notes（中文）：v3.7.8 包名称更名，同时标出三种 ConvRot 层级

## 概述

**包名称现在同时标出三种 ConvRot 层级。** Registry 显示名称、包描述、以及 README 标题（英文与中文）现在为 `ComfyUI-HSWQ-ConvRot-INT8/ConvRot-W4A8/ConvRot-NVFP4-Loader-and-Tools`，并在既有的 ConvRot INT8 与 ConvRot NVFP4 之外加入 **Flux1 Hybrid ConvRot W4A8** 加载器，与 v3.7.6、v3.7.7 起加载器已支持的格式相对应。

本版本**仅是更名**。包含四个文档/元数据提交（`2cade57`、`faeb5f8`、`64a1aab`、`074fa30`）：`pyproject.toml` 的 `DisplayName` 与 `description`、两个 README 的 H1 标题、以及双语 changelog 条目。节点类、`weight_dtype` 选项、文件名、加载行为与量化逻辑均不变，未触碰任何代码。

---

## 特性

- **Registry 显示名称**：`ComfyUI-HSWQ-ConvRot-INT8/ConvRot-W4A8/ConvRot-NVFP4-Loader-and-Tools` —— 把 INT8、W4A8、NVFP4 三种 ConvRot 层级并列标出。
- **包描述**：在 SDXL/Z Image ConvRot INT8/Hybrid ConvRot NVFP4 加载器、KREA2 ConvRot INT8 加载器与各类工具之外，加入 **Flux1 Hybrid ConvRot W4A8 Loader**。
- **README 标题（英文 + 中文）**：同一新名称，两个语言侧在同一提交内同步修改。
- **双语更新日志**：v3.7.8 条目以与此前版本相同的结构加入 `changelog.md` 与 `zhmd/CHANGELOG.md`。

---

## 兼容性

- **仅名称变更**：从 v3.7.7 升级不改变任何行为。工作流、节点名、`weight_dtype` 下拉选项、模型文件均保持原样。
- **Registry 说明**：显示名称与描述在该版本发布到 Registry 时生效；发布与本 Release 是两个独立的步骤。
