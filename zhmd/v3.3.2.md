## 摘要

**v3.3.2** 修复 Z Image / ZIT **ConvRot NVFP4** 在 **DistOrch VRAM purge 后的第 2 次生成**出现的**椒盐噪声**。

purge 之后 Distorch node 会重建栈。若 INT8 decode wrap 丢掉了 NVFP4 stack 标记，后续“upgrade”会把 **Tensor Core 产品**路径叠到 **Comfy parity** 之上。refresh 只剥掉 TC 层，重载后留下 **双重在线 act rotate** —— 第 1 次生成正常，第 2 次起出现噪声。

现于 INT8 wrap 中保留标记，parity refresh 不再二次武装 rotate。

## 修复

### DistOrch purge 后的双重在线 act rotate

- **症状：** 第 1 次生成正常 → DistOrch / General Purge VRAM → 第 2 次在 Z Image / ZIT ConvRot NVFP4 上出现椒盐 / 纹理崩坏。
- **原因：** INT8 decode wrap 丢掉 NVFP4 stack 标记 → TC 产品路径叠在 Comfy parity 上 → DistOrch refresh 留下 **两层** 在线 act rotate。
- **修复：** 在 INT8 wrap 中保留 NVFP4 / parity stack 标记（`nodes/nvfp4/comfy_quant_nvfp4.py`、`nodes/zimage_nvfp4/nvfp4_comfy_parity.py`、`patches/comfy_quant_int8.py`），使 refresh 只重新武装一层 rotate。

## 操作说明

1. 将本自定义节点更新到标签 **v3.3.2**（提交 `c04811e` 或之后的 `main`）。
2. 完全重启 ComfyUI。
3. 使用 HSWQ NVFP4 / INT8 时，工作流末尾仍使用 **General Purge VRAM V2**（打开 **`HSWQ`**）。
4. 确认 purge 后的第 2 次（及之后）生成不再因双重 act rotate 出现椒盐噪声。
