# Release Notes（中文）：v3.7.1 HSWQ Load CLIP Vision 节点 - 支持 ConvRot INT8 CLIP Vision 模型

版本 **v3.7.1** 新增 **HSWQ Load CLIP Vision** 节点，作为 ComfyUI 内置 "Load CLIP Vision" 的直接替代品，原生支持 **ConvRot INT8** CLIP Vision 模型。

代码提交 `7180476`。完整节点文档：[README.md（Nodes 章节）](https://github.com/ussoewwin/ComfyUI-HSWQ-Loader-and-Tools/blob/main/README.md)。

---

### 1. 新增功能

1. **HSWQ Load CLIP Vision 节点**（分类 `loaders`，输入 `clip_name`，输出 `CLIP_VISION`）：
   - Float pack（无 `comfy_quant`）：与 stock "Load CLIP Vision" 逐字节等价 — 相同的 key-layout 自动检测（OpenAI `visual.` 前缀、ViT-g/H、SigLIP、SigLIP2、ViT-L-336（+LLaVA projector）、ViT-L、DINOv2、DINOv3），相同预处理，相同输出（`last_hidden_state` / `image_embeds` / `penultimate_hidden_states` / `image_sizes` / `mm_projected`）。
   - ConvRot INT8 pack（如 `CLIP-ViT-H-14_hswq_convrot_int8.safetensors`）：ConvRot INT8 层被原地替换为 `mixed_precision_ops` `Linear`（`int8_tensorwise`，`convrot=True`），其 INT8 codes / `weight_scale` 被加载，塔通过 `comfy_kitchen` 运行真正的 INT8 GEMM 而非反量化到 float。
   - 标准 `CLIP_VISION` 输出 — 可供 `CLIP Vision Encode`、IPAdapter、Style Model、PuLID 等消费。

2. **非 INT8 格式的格式守卫**：
   - 仅接受所有 `comfy_quant` 层均为 `int8_tensorwise` 的 pack。
   - 任何其它声明的格式（`nvfp4`、`float8_e4m3fn`、`float8_e5m2`、`w6a8_int8`、`asym_w4a8_int8`、`mxfp8`、`convrot_w4a4` 或不可读）均以显式 `RuntimeError` 拒绝，而非静默地把 codes 当作 float 运行。
   - Float pack（无 `comfy_quant`）仍保持 stock 路径逐字节不变。

---

### 2. 各架构验证

| 架构 | 模型 Checkpoint | 结果 |
| :--- | :--- | :--- |
| **CLIP Vision FP16（stock 路径）** | `CLIP-ViT-H-14.safetensors` | **PASS**：image_embeds (1, 1024)，全部 finite |
| **CLIP Vision ConvRot INT8** | `CLIP-ViT-H-14_hswq_convrot_int8.safetensors` | **PASS**：92 / 92 声明层全部 armed，INT8 GEMM（`comfy_kitchen::int8_linear`、`quantize_int8_rowwise_convrot64_kernel`），params.convrot=True，scale float32 (1280, 1)，cosine(INT8, FP16) = 0.999988，rel_l2 = 0.496 %，last_hidden_state cos = 0.999090，全部 finite |
| **CLIP Vision FP16（OpenAI .bin）** | `clip-vit-large-patch14-336.bin` | **PASS**：model_type=clip_vision_model，emb=(1, 768)，finite |
| **CLIP Vision FP16（dynamic VRAM）** | `CLIP-ViT-H-14.safetensors`（aimdo + ModelPatcherDynamic） | **PASS**：cosine 0.999988，vram allocated 1 MB |
| **非 INT8 格式守卫** | 合成 nvfp4 pack | **PASS**：抛出 RuntimeError（显式拒绝，无静默垃圾） |
